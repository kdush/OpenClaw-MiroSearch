# 行为准则

本项目致力于营造开放、专业且相互尊重的协作环境。

## 我们期望的行为

- 讨论聚焦技术事实与可验证证据。
- 尊重不同的背景、经验与观点。
- 在评审与讨论中给出可执行的建议。
- 及时纠正错误，并保持透明沟通。

## 不可接受的行为

- 人身攻击、侮辱性语言或骚扰行为
- 恶意刷屏、挑衅或歧视性言论
- 未经允许公开他人的隐私信息
- 明知存在风险仍传播敏感漏洞细节

## 执行与处理

维护者可以编辑或删除违反本行为准则的内容，或限制与其相关的互动。对于严重或反复发生的违规行为，维护者可以暂时中止或永久取消相关人员的参与权限。

维护者评估举报时，应考虑事件背景、影响与重复程度，采取与违规程度相称的处理措施，并在可行范围内保护举报者和受影响参与者的隐私。
