# 路线图

[English](./ROADMAP.md)

本路线图将已实现的 `v0.2.11` 基线与计划工作分开。逐版本历史记录统一放在
[变更日志](./CHANGELOG_zh.md)中。

## 当前基线：`v0.2.11`

仓库当前已经实现：

- FastAPI 研究任务 API，包括轮询、SSE 回放、定向取消、指标、fail-closed Bearer
  鉴权和请求限流；
- 基于 arq 的异步执行，以及由 Valkey 支持的队列、任务元数据、事件、结果、质量
  元数据和共享结果缓存；
- Gradio UI、兼容 API 和由 API 后端支持的重连链路；
- 可配置的研究模式、检索路由、深度、校验轮次、输出篇幅和分阶段模型路由；
- 通过 SearXNG 与已配置商业搜索服务完成的多提供商检索，包括有界回退和 Key
  轮换；
- [抓取迭代计划](./SCRAPING_ITERATION_PLAN_zh.md)中 T1-T8 对应的单 URL 抓取安全与
  内容提取能力。

代码库内部使用 MCP 管理工具子进程，但目前没有可供外部客户端连接的公开 MCP
Server。下文适配层属于计划工作，尚未实现。

## `v0.3.0`：站点友好的批量抓取

计划结果：在不削弱现有单 URL 安全约束的前提下完成抓取任务 T9。

- 增加有界的多 URL 抓取，并隔离单条失败；
- 抓取符合条件的页面前遵循 `robots.txt` 判定；
- 增加按站点控制的并发与请求速率；
- 对 `429` 和暂时性 `5xx` 响应执行有界退避；
- 用自动化测试覆盖批次超时、SSRF、重定向、限制和部分失败。

## `v0.4.0`：质量评测与可观测性

计划结果：在继续调整检索策略前，让研究质量与运行行为能够被衡量。

- 建立有版本的评测集和可复现的评分流程；
- 衡量答案可用性、引用覆盖、来源多样性、时效性、延迟和成本相关计数；
- 以稳定字段语义暴露任务阶段与提供商级遥测；
- 增加可在 CI 中运行的回归阈值，避免所有测试都必须调用付费外部服务。

## `v0.5.0`：标准 MCP 适配层

计划结果：在现有研究运行时之上提供受支持的 MCP 集成层。

- 支持本地 `stdio` 和远程 Streamable HTTP 传输；
- 通过 MCP tools、resources 和 prompts 暴露小而稳定的接口；
- 将 MCP 调用映射到现有异步任务生命周期，不重复实现研究引擎；
- 定义鉴权、授权边界、结构化错误、取消、超时和进程生命周期行为；
- 为两种传输增加协议契约与兼容性测试；
- 仅在 Server 可运行且经过测试后，发布部署与客户端接入文档。

## `v1.0`：受支持的生态

计划结果：将稳定运行时和 MCP 适配层发展为可维护的集成生态。

- 发布兼容性与弃用策略；
- 提供有版本的示例与集成模板；
- 定义提供商、工具与部署档位的扩展点；
- 文档化升级、备份、恢复和运维支持预期。

## 规划规则

- 只有在代码与自动化检查均存在后，路线图任务才转入变更日志；
- 文档必须区分当前行为和提议设计；
- 公共契约应尽量复用现有任务与结果模型；
- 增加新传输和部署模式时，安全默认值继续保持 fail-closed。
